Dotfiles

Daily commands from this repo. Zsh, Git, tmux, Neovim, Ghostty, and Spacemacs.

Shell

  • ls

    eza with icons. No git status.

  • ll

    eza with icons, git status, and details.

  • la

    Same as ll, including dotfiles.

  • cd

    zoxide. Plain cd is the z command.

  • cat

    bat, when it is installed.

  • reload

    Source ~/.zshrc in this shell.

  • ta

    Attach to a tmux session, or start one.

  • update

    macOS software update, Homebrew upgrade, and Oh My Zsh.

  • bbu

    Write Brewfile.snapshot. It does not edit the tracked Brewfiles.

Git

  • gs

    git status -sb.

  • gl

    One-line graph of all branches.

  • gp

    git push.

  • gpl

    git pull --rebase --autostash.

  • gc

    git commit -m. Pass the message in quotes.

  • lg

    Open LazyGit.

Tmux

Prefix is Ctrl-a.

  • C-a r

    Reload ~/.tmux.conf.

  • C-a |

    Split right, in the current directory.

  • C-a -

    Split down, in the current directory.

  • C-a c

    New window in the current directory.

  • C-a Space

    Jump back to the previous window.

  • C-a n / p

    Next or previous window.

  • C-a m

    Zoom the current pane.

  • C-a H J K L

    Resize the pane by 5 cells.

  • C-a C-j

    fzf list of other sessions.

  • v then y

    In copy mode, select and copy.

Neovim

Leader is Space.

  • Space w

    Save the file.

  • Space q

    Close the window.

  • Space Q

    Force-quit every window.

  • Space e

    Toggle the file tree.

  • Space ff

    Fuzzy file search.

  • Space fg

    Live grep in the project.

  • Space fb

    Switch buffer.

  • Space fo

    Reopen a recent file.

  • Space cf

    Format the buffer.

  • Space gg

    Open LazyGit.

  • [d / ]d

    Previous or next diagnostic.

  • Space Space

    Clear the search highlight.

Ghostty

  • Cmd+`

    Toggle the quick terminal.

  • Cmd+Opt+h j k l

    Move between splits.

  • Right-click

    Paste.

  • Select

    Copy the selection.

Spacemacs

Leader is SPC. Press ESC first if a key does nothing.

  • SPC SPC

    Helm command menu. This is M-x.

  • SPC '

    Popup Ghostel. TERM is xterm-ghostty.

  • SPC b b

    Helm buffer list.

  • C-c d

    In that list, kill the highlighted buffer and stay open.

  • SPC b d

    Kill the current buffer.

  • SPC f e R

    Reload ~/.spacemacs after an edit.

  • SPC q R

    Restart Emacs so startup settings apply.
