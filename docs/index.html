Dotfiles

Daily commands from this repo. Zsh, Git, tmux, Neovim, Ghostty, and Spacemacs.

Shell

  • ls

    eza with icons. No git status.

  • ll

    eza with icons, git status, and details.

  • la

    Same as ll, including dotfiles.

  • cd

    Aliased to zoxide's z command when zoxide is installed.

  • cat

    bat, when it is installed.

  • mkcd DIR

    Create a directory and enter it.

  • fff

    Open the fff MCP file manager.

  • reload

    Source ~/.zshrc in this shell.

  • ta

    Attach to the first tmux session, or start one.

  • update

    macOS: system, Homebrew, and Oh My Zsh. Linux: apt and Oh My Zsh.

  • bbu

    Write Brewfile.snapshot. It does not edit the tracked Brewfiles.

  • gscan [since] [limit]

    Summarize repo churn, authors, bug hotspots, velocity, and firefighting signals.

Git

  • gs

    git status -sb.

  • gl

    One-line graph of all branches.

  • gp

    git push.

  • gpf

    git push --force-with-lease.

  • gpl

    git pull --rebase --autostash.

  • gaa

    Stage every change in the repository.

  • gc

    git commit -m. Pass the message in quotes.

  • lg

    Open LazyGit.

Spacemacs

Hybrid editing: leader is SPC in normal state and M-m in insert or Emacs state. , opens mode-specific commands.

Configured with Helm, Treemacs, Ghostel, Org capture and agenda, Python LSP with Pyright, auto-completion, syntax and spell checking, Git VC, and automatic light/dark themes.

Core

  • SPC SPC

    Helm command menu. This is M-x.

  • SPC '

    Popup Ghostel. TERM is xterm-ghostty.

  • SPC TAB

    Switch to the previous buffer.

  • SPC T n

    Cycle the configured Spacemacs themes manually.

  • SPC q R

    Restart Emacs so startup settings apply.

Files and projects

  • SPC f f

    Find a file with Helm.

  • SPC f r

    Open a recent file.

  • SPC /

    Search the current project.

  • SPC p f

    Find a file in the current project.

  • SPC p p

    Switch projects.

  • SPC f t

    Open the Treemacs file tree.

  • SPC p t

    Toggle the current project in Treemacs.

Buffers and windows

  • SPC b b

    Helm mini: buffers, recent files, and related sources.

  • C-c d

    In that list, kill the highlighted buffer and stay open.

  • SPC b d

    Kill the current buffer.

  • SPC w / / SPC w -

    Split the window right or below.

  • SPC w h j k l

    Move between windows.

  • SPC w m

    Maximize or restore the current window.

  • SPC w d

    Delete the current window.

Org, code, and configuration

  • SPC a o c

    Start Org capture. macOS templates: p post-mortem, o outreach, d study day.

  • SPC a o a

    Open the Org agenda list.

  • , g d / , g r

    With LSP active, find a definition or references.

  • , a a / , r r

    Run an LSP code action or rename a symbol.

  • , = b

    Format the current buffer with LSP.

  • SPC e n / SPC e p

    Jump to the next or previous error.

  • SPC e l

    Toggle the Flycheck error list.

  • SPC g v

    Open the built-in version-control command prefix.

  • SPC f e d

    Open ~/.spacemacs for editing.

  • SPC f e R

    Sync layers and reload the Spacemacs configuration.

Neovim

Leader is Space.

  • Space w

    Save the file.

  • Space q

    Close the window.

  • Space Q

    Force-quit Neovim and every open buffer.

  • Space e

    Toggle the file tree.

  • Space ff

    Fuzzy file search.

  • Space fg

    Live grep in the project.

  • Space fb

    Switch buffer.

  • Space fo

    Reopen a recent file.

  • Space cf

    Format the buffer.

  • Space gg

    Open LazyGit.

  • Space gd / gh

    Open Diffview or the current file's Git history.

  • Space xx

    Open project diagnostics in Trouble.

  • gd / gr / K

    LSP definition, references, or hover documentation.

  • Space ca / Space rn

    LSP code action or symbol rename.

  • [d / ]d

    Previous or next diagnostic.

  • Ctrl-h j k l

    Move between Neovim windows and tmux panes.

  • Ctrl-\

    Toggle the floating terminal.

  • Space Space

    Clear the search highlight.

Ghostty

  • Cmd+`

    Toggle the quick terminal.

  • Cmd+Opt+h j k l

    Move between splits on macOS.

  • Ctrl+Alt+h j k l

    Move between splits on Linux.

  • Right-click

    Paste.

  • Select

    Copy the selection.

Tmux

Prefix is Ctrl-a.

  • C-a r

    Reload ~/.tmux.conf.

  • C-a |

    Split right, in the current directory.

  • C-a -

    Split down, in the current directory.

  • C-a c

    New window in the current directory.

  • C-a Space

    Jump back to the previous window.

  • C-a n / p

    Next or previous window.

  • C-a m

    Zoom the current pane.

  • C-a H J K L

    Resize the pane by 5 cells.

  • C-a C-j

    fzf list of other sessions.

  • C-a I

    Install tmux plugins with TPM.

  • v then y

    In copy mode, select and copy.
